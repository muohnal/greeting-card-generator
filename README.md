# 고객 안내문 자동 생성 (인사카드)

고객 이름만 바꿔가며 인사 카드 이미지를 **최대 500장**까지 만들어 ZIP으로 받고,
카톡·문자·인스타로 바로 공유하는 도구입니다.

**👉 https://muohnal.github.io/greeting-card-generator/**

폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있고, 그 뒤로는 인터넷 없이도 실행됩니다.

## 기능

- 고객명 입력 (쉼표 구분 / 한 줄에 한 명 / CSV 업로드)
- 담당자 정보 · 인사말 · 서비스 항목 · 연락처 문구 모두 수정 가능
- 로고 업로드 (크기 · 위치 조절)
- 색 테마 6종 + 배경 · 메인 · 포인트 색 개별 지정
- 글꼴 11종 (4종은 파일에 내장되어 인터넷 없이도 사용 가능)
- 진행률 · 예상 시간 · 일시정지 · 취소
- PNG 1080px 출력, ZIP 200장씩 분할
- 카톡 · 문자 · 인스타 공유 (OS 공유 시트)

## 만들어지는 파일

`001_김원정.png` 형식으로 순번이 붙고, 200장씩 `인사카드_001-200.zip` 으로 묶입니다.

## 어떻게 동작하나

전부 **브라우저 안에서만** 처리됩니다. 서버가 없고, 입력한 고객 이름은 어디로도 전송되지 않습니다.

- 카드는 Canvas 2D로 직접 그립니다 (500장 약 14초)
- 이름을 뺀 카드를 한 번만 그려두고 장마다 인사말만 다시 얹습니다
- ZIP은 외부 라이브러리 없이 직접 만듭니다 (무압축 STORE 방식 — PNG는 이미 압축되어 있어 다시 압축해도 1~2%밖에 줄지 않습니다)
- 설정은 브라우저에 저장되지만 **고객 명단은 개인정보라 저장하지 않습니다**

## 처음 쓸 때

담당자 이름 · 전화번호 · 지점명과 회사 로고는 비어 있습니다.
한 번 입력하시면 그 브라우저가 기억합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (글꼴 내장) |
